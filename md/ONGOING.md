# Ongoing Work

- Added Multi-State support to HUD Bar/Icon widgets (mirrors items' Multi-State concept): a "Multiple States" checkbox opts a widget into a `states` list of independent texture sets (Bar's filled/empty, Icon's icon), switched by a `LinkableValueField` State Index (hardcoded literal or Blocky link, compiled into `HudValueSources` same as Value/Max). Each state's texture slots support their own spritesheet Frame link. Text widgets don't get this (a texture-set swap doesn't apply to plain text). See `YCS_V3_Injection_and_Lifecycle.md`'s HUD section for the full writeup. Not yet manually tested in-game — worth a launch + hand-authored test layout pass next session (same verification HUD's original build used).
